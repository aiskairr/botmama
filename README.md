# Телеграм-бот для поздравления мамы

Коротко: бот отвечает на сообщение «мама привет» готовым поздравлением.

1) Получите токен у @BotFather в Telegram и вставьте его в файл `.env` в корне проекта:

```
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_БОТФАВЕРА
```

2) Установите зависимости и запустите бота:

```bash
python -m pip install -r requirements.txt
python bot.py
```

3) Откройте чат с ботом и напишите:

```
мама привет
```

Бот ответит текстом поздравления от Алины.
